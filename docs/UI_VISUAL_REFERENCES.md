## Design direction

Pair the planned petrol/blue-black hero and large Korean type with restrained coral/cobalt accents that encode real series in the actual count/rate plot. Use one purposeful route/telemetry cue for atmosphere, with explicit labels, units, and explanation carrying the evidence. A showy opening is appropriate, but every chart mark must map to saved evidence; no random telemetry, invented KPI tiles, radar, glass panels, or decorative data grids.

The source observations above come from official page text/search extracts, not a fresh screenshot audit. The indexed F1 article is from 2020; its reported telemetry scale describes that article, not this project or necessarily current F1 operations. No upstream code was used, so no upstream code license is being relied on. This visual direction does not change the frozen benchmark/selection, original ten evidence hashes, or presentation-v2 outputs.
